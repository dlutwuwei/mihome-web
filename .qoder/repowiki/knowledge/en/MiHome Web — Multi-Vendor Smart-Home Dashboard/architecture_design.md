Entry `src/index.ts` calls `bootstrapProviders()` (providers module) to register every vendor adapter against the shared registry in `server_core`, then creates the Express app via `createApp()` (`app.ts`) which mounts all route modules under `/api/*`. The same process also serves the Vite-built React SPA from `public/`. Cross-child wiring is therefore: providers → server_core registry → routes → server_core services; controls sits between providers and routes as the normalization layer that turns raw `VendorField`s into `DeviceDetail` panels. Runtime profile overrides live on disk under `data/profiles/<vendor>/` and are hot-reloaded without restart, while the client-side dashboard consumes the normalized panel schema described in README.md.
