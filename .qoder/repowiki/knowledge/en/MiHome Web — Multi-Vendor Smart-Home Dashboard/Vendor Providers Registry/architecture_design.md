Each subdirectory under src/providers/ implements one `VendorProvider` contract defined in `types.ts`, exposing an object with id/name/authModes plus lifecycle methods (loginPassword/sendSms/beginQr/listDevices/getDeviceDetail/setProperty/runAction). The top-level `index.ts` is the only wiring point: `bootstrapProviders()` calls `registerVendor` from `../core/registry.js` for each adapter after invoking `bootstrapProfiles()`. This keeps vendor implementations isolated — they never import each other — and lets the rest of the app discover providers uniformly through the registry. Cross-cutting types (`VendorSession`, `PendingAuth`, `DeviceSummary`, `DeviceDetail`, etc.) are declared once in `types.ts` and consumed by every provider.
