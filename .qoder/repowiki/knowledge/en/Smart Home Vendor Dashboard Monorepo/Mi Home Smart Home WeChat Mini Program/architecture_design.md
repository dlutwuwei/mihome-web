Standard WeChat Mini Program layout under `miniprogram/`: `app.js` + `app.json` register pages (`device`, `devices`, `settings`) and a global app instance; `components/device-card` and `components/gauge-control` are reusable WXML/WXSS components consumed by pages. State is centralized in `stores/deviceStore.js`, built with `mobx-miniprogram` (observable/action/runInAction) and bound to views through `mobx-minigo-program-bindings` (vendored under `miniprogram_npm`). The store owns all async flows — loading devices, fetching live data, reading/writing properties, and running actions — and delegates HTTP calls to `services/api.js`, which wraps `wx.request` with Bearer-token auth, base URL normalization, and `wx.getStorageSync`/`setStorageSync` persistence of `baseUrl` and `apiKey`. Pure helpers live in `utils/device.js` (decorateDevice, decorateServices, findProperty/findAction, clampPropertyValue). Dependency direction is one-way: pages → stores → services → wx.* APIs, with no cross-page imports.
