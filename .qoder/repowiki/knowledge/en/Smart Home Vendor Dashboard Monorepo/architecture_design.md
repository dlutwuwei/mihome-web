The root `src/index.ts` is the sole entry point: it calls `bootstrapProviders()` from the providers module to register every vendor adapter against the shared registry in server_core, then creates the Express app via `createApp()` (app.ts) which mounts all route modules under `/api/*`. The same process serves the Vite-built React SPA from `public/`. Cross-child wiring follows a fixed pipeline — providers expose a normalized `VendorProvider` interface, routes consume it through server_core services, and controls sits between providers and routes as the normalization layer that turns raw `VendorField`s into `DeviceDetail` panels. Runtime profile overrides live on disk under `data/profiles/<vendor>/` and are hot-reloaded without restart, while the client-side dashboard consumes the normalized panel schema described in README.md. Documentation of vendor protocol reverse-engineering lives under `docs/` alongside screenshots of account-status flows.
